# DHT Temperature Monitoring System

## Description
This project demonstrates a basic embedded system using Arduino and DHT sensor.
Temperature and humidity are monitored and an LED is used as an alert indicator.

## Components Used
- Arduino UNO
- DHT22 Sensor
- LED
- 220Ω Resistor

## Working
- DHT sensor reads temperature and humidity
- Values are displayed on Serial Monitor
- LED turns ON if temperature exceeds 30°C

## Platform
- Wokwi Simulator
